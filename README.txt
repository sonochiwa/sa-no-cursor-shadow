No Cursor Shadow v1.0.0

Removes the offset translucent shadow from the normal and map cursors in
GTA San Andreas. It does not change any other shadows.

Installation

1. Close the game.
2. Copy NoCursorShadow.asi into the directory containing gta_sa.exe.
3. Start the game normally.

Requires GTA San Andreas 1.0 US and an ASI loader. Remove
NoCursorShadow.asi to uninstall the fix.

Source code: https://github.com/sonochiwa/sa-no-cursor-shadow
